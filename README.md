# n8n Lead Capture Automation - AC Repair

Automated lead capture workflow built with n8n that converts website leads into CRM contacts instantly.

🔗 **Live Demo:** https://www.loom.com/share/db368df8e6294ec092e3ea7a3baeb6f

### What This Workflow Does:
1.  **Webhook** - Captures lead data (Name, Email, Service) from website form
2.  **IF Node** - Validates if email exists
3.  **HubSpot** - Auto-creates/updates contact in CRM
4.  **Gmail** - Sends instant confirmation email to lead

### Tech Stack:-
- n8n (No-Code Automation)
- HubSpot CRM API
- Gmail API
- Webhook

### Result:
✅ Lead response time: 0 to 5 seconds
✅ No manual data entry
✅ Works 24/7

### How to Use:
1. Import `workflow.json` into n8n
2. Add your HubSpot Private App Token
3. Add your Gmail credentials
4. Activate workflow
